# Roadwise routing maps

Routing maps for the Roadwise Android app, downloaded from the app's "Routing maps" screen.
Each release holds one region's GraphHopper routing graph as a zip; `regions.json` lists them.

Map data © OpenStreetMap contributors, available under the
[Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/1-0/). These maps are
derived databases built from OpenStreetMap extracts by [Geofabrik](https://download.geofabrik.de)
and are themselves available under the ODbL. They are built with
[GraphHopper](https://www.graphhopper.com) 11.1 using Roadwise's `routing/build-map.sh` and
`routing/config.yml`.
